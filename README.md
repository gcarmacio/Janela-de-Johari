# Janela-de-Johari
Este projeto apresenta a aplicação da Janela de Johari, uma ferramenta de autoconhecimento que permite identificar características pessoais a partir da percepção própria e da visão das outras pessoas. A atividade explora quatro áreas: Aberto, Ponto Cego, Oculto e Desconhecido, proporcionando uma reflexão sobre personalidade, comportamento e desenvolvimento pessoal.
